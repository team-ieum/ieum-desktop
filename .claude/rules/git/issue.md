# 이슈
- 제목: `[<유형>] <한국어 설명>` — 유형은 대문자 `FEAT`·`FIX`·`CHORE`. 단계가 있는 작업은 끝에 `(… 1a)`처럼 단계를 단다
- 라벨·담당자·마일스톤은 쓰지 않는다
- 본문은 유형별로:
  - `FEAT`: `## 왜`(지금 무엇이 안 돼서 필요한지) → `## 범위` → `## 설계 때 정할 것`(조사에서 나온 걸림돌·영향받는 파일) → `## 범위 밖` → 참고 문서 경로
  - `FIX`: 현상 한 줄 → `- 원인:` → `- 기대:`
  - `CHORE`(확인·정리): 할 일을 `- [ ]` 체크리스트로
- 관련 이슈·PR은 `#번호`로 잇는다. 작업 브랜치는 `feat/<번호>-…`, PR 본문은 `Closes #<번호>`
